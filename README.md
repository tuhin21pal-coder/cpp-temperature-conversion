# Temperature Converter (C++)

A menu-driven temperature conversion program written in C++ that converts temperatures between Celsius, Fahrenheit, and Kelvin.

# Features

Converts Celsius to Fahrenheit and Kelvin.
<br>
Converts Fahrenheit to Celsius and Kelvin.
<br>
Converts Kelvin to Celsius and Fahrenheit.
<br>
Supports uppercase and lowercase unit inputs.
<br>
Validates source and target temperature units.
<br>
Prevents temperatures below absolute zero.

Variables and data types (double, char)
<br>
User input and output (cin, cout)
<br>
Conditional statements (if-else)
<br>
Logical operators (&&, ||)
<br>
Arithmetic operations
